# Personal Agent Skills

[简体中文](README.zh-CN.md)

A personal collection of Agent Skills that I write and use to capture reusable workflows, prompt protocols, and reference materials.

These skills evolve through real-world use. They serve my workflow first, while also providing examples for designing and implementing Agent Skills.

## Available Skills

| Skill | Purpose |
| --- | --- |
| [thinking-methodology](thinking-methodology/SKILL.md) | For complex, ambiguous, or consequential problems: uncover unknowns, select appropriate thinking tools, and turn analysis into actionable plans. |
