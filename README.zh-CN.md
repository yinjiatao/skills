# 我的个人技能仓库

[English](README.md)

这是我个人编写并持续使用的技能仓库，用来沉淀可复用的工作方法、提示协议和参考资料。

这些技能会随着实际使用不断调整；它们首先服务于我的工作流，也欢迎作为设计和实现 Agent Skill 的参考。

## 当前技能

| 技能 | 用途 |
| --- | --- |
| [thinking-methodology](thinking-methodology/SKILL.md) | 在复杂、模糊或重要的问题中，先发现未知，再选择思维工具解释问题，并输出可落地的执行方案。 |
